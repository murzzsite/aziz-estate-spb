# Азиз — брокер новостроек и риелтор, Санкт-Петербург

Лендинг: чистый HTML/CSS/JS, GitHub Pages. Заявки уходят через Cloudflare Worker (lead-relay) в Telegram, ref `FM65KP9HS4`.

## Что на сайте
- Hero с разводным мостом: фото раскрывается от центра, как пролёты моста.
- Четыре услуги (новостройки 0 ₽, вторичка 2–3 % от 150 000 ₽, дом 0 ₽, ипотека 0 ₽), у каждой своё поле цвета.
- Живой калькулятор платежа: цена, взнос, ставка, срок; показывает платёж, выигрыш от ставки на пункт ниже и услугу Азиза.
- Список «Что входит в работу», лента этапов сделки, FAQ с двумя главными возражениями, форма заявки.

## Что подтвердить с клиентом
- Телефон и адрес не даны: на сайте только Telegram @aziz_estate и aziz.toprealtors.ru.
- Ставка и срок в калькуляторе по умолчанию (10 %, 20 лет) условные.
- Формулировки про сданные дома, рассрочку и ипотеку застройщика даны в общем виде («там, где они есть»).
- Реквизиты оператора в privacy.html не указаны.
